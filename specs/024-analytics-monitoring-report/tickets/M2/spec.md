# M2: Overview monitoring

Project: Horizon Blog. Service: frontend. Source: ../../spec.md and approved-mockup.png.
Dependencies: M1. Blockers: none.

## Acceptance criteria
1. Show real daily views with numeric axis and accessible text, empty/freshness states.
2. Views are right-aligned counts with no bounded meter; completion uses 0-100 percent.
3. Search, sort, paging and linked details preserve UTC dates and support mobile.

Non-goals: API/schema/auth changes, new dependencies, publication. Existing unknown/error states remain explicit.
